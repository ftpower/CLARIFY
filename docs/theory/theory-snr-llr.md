## 0. 一页摘要

把 LLM 推理类比为级联通信系统：**层 = 信道级联，token 序列 = 时间维反馈环**。
研究对象是时空 LLR 场 LLR(ℓ, t)——正确答案（外部）与模型自身答案（内部）在
每层每 token 的对数似然比轨迹。观测阶段只画轨迹、统计样本三分占比，不做干预；
干预（层间回退 / 定向纠错）仅当观测支持时进入设计。训练侧候选暂存 §7；
监督-校验思想两条路线（线性监督矩阵 §8 / 残差流结构适配 §9）共用阶段 1 存档。

## 1. 问题形式化

### 1.1 通信类比与边界

| 通信构件 | LLM 对应物 | 成立性 |
|---|---|---|
| 信源 | 输入问题 x + 事实知识（率失真框架已覆盖） | ✅ 已有理论 |
| 信道 | L 层级联变换（z_ℓ = W_U·h_ℓ） | ⚠️ 无加性噪声，是确定性复合 |
| 接收信号 | 正确答案 token 的逐层 logit | ⚠️ **外部标签**，非物理信号 |
| 反馈环 | 自回归（输出 token → 上下文） | ⚠️ token 不是"误差" |

**三个物化警告**（第一性原理，实验全程自查）：
1. **无发射端**：模型从未"编码 y*"，z_ℓ[y*] 只是外部标签在网络分布中的排名历史；
2. **无加性噪声**：层间是确定性函数，"噪声"是人为命名，不是物理来源；
3. **无码字**：没有发送端冗余，层间 LLR 合并只是分集（且各层高度相关，增益上限
   被锁死），不是译码。

> 推论：本方向**不承诺干预有效**。观测侧回答"信息如何在层/时间上丢失"是主要
> 交付物；干预侧只有在 §6 判读通过后才设计。

### 1.2 研究对象：时空 LLR 场

对样本 x、层 ℓ ∈ {0..L}、答案 token 位置 t：
- 外部信号：s_ext(ℓ,t) = max_{a∈A} z_ℓ[a]（A = 答案别名集）
- 内部信号：s_self(ℓ,t) = z_ℓ[y_L*]（y_L* = 最终层 argmax，模型自身答案）
- 噪声与 LLR、秩的定义见 §2。

## 2. 信号与噪声的定义（本阶段核心）

### 2.1 定义约束

- **C1 尺度免疫**：h_ℓ 范数逐层膨胀、softmax 温度逐层变化 → 跨层比较只能用
  对单调变换不变的量（**秩**）或说明归一化方式；LLR 幅度只在层内比较。
- **C2 噪声不得含信号**：TriviaQA 答案有别名（"MAGMA"/"Magma (disambiguation)"），
  噪声必须排除全部别名：n = max_{y∉A}，否则 SNR 被系统性低估。
- **C3 成对定义**：外部信号（标签视角）与内部信号（模型自洽视角）必须并行记录，
  单画外部轨迹只会得到平凡的"正确样本上升"曲线。
- **C4 可接干预**：定义需保留幅度（LLR 置信度），不能只留秩。

### 2.2 候选定义

| 量 | 定义 | 尺度免疫 | 用途 |
|---|---|---|---|
| 外部 LLR | LLR_ext(ℓ) = s_ext(ℓ) − max_{y∉A} z_ℓ[y] | 平移✓ 缩放✗ | 干预信号（层内） |
| 内部 LLR | LLR_self(ℓ) = s_self(ℓ) − max_{y≠y_L*} z_ℓ[y] | 同上 | 干预信号（层内） |
| 外部秩 | r_ext(ℓ) = rank_ℓ(A)/V | ✅ 完全免疫 | **主诊断量** |
| 内部秩 | r_self(ℓ) = rank_ℓ(y_L*)/V | ✅ 完全免疫 | **主诊断量** |
| 聚合噪声 | n_agg(ℓ) = logsumexp_{y∉A} z_ℓ[y] | 温度混杂 | 辅助（长尾 vs 单峰） |
| 序列级 | Σ_t ln P_ℓ(y*_t | y*_<t, x) | 温度混杂 | 首 token 对照 |

### 2.3 推荐组合（定稿候选）

1. **诊断主图**：r_ext(ℓ)、r_self(ℓ) 轨迹（首个内容 token，跳过标点/停用词前缀）
2. **干预信号**：LLR_ext(ℓ)、LLR_self(ℓ)（层内幅度）
3. **噪声双轨**：对抗 max_{y∉A} + 聚合 logsumexp_{y∉A}
4. **对照**：首内容 token vs 序列级 logprob（不一致时以序列级为准）

## 3. 机制假说

### 3.1 层维（H1）：样本按成对轨迹三分

错误样本的 (r_ext, r_self) 轨迹天然分三类（分类标准由定义给出，非假说）：

| 类型 | r_ext | r_self | 解读 | 干预可用性 |
|---|---|---|---|---|
| 追不上型 | 全程大 | 早期即小 | 模型自身答案从早期就赢，外部答案从未被考虑 | **无信息可找**（LLR_ext 全程负） |
| 塌陷型 | 早期小、后期变大 | 后期变小（接管） | 外部答案曾占优，后期被覆盖 | 回退有信息可找 |
| 不确定型 | 全程中等 | 全程中等 | 长尾分布，无明确赢家 | 待定 |

**H1 的可检验含义**：三分占比 = 层间回退类干预的可救上限（若追不上型 >70%，
任何 logit 回退的 KW 救回率上限 ≈ 塌陷型占比）。

### 3.2 时间维（H2）：吸收态假设（含混杂警告）

自回归错误可能"吸收"（前文错 → 后续错）。**反事实设计要求**：观测相关性
P(s_{t+1}=C|s_t=E) 低不能归因于传播——共同原因（问题难度）可完全解释。
唯一有效设计：同一批问题 × {正确前文, 错误前文, 随机前文} 对照后续正确率。

## 4. 可检验预测

- **P1**（平凡但必查）：KC 样本 r_ext(ℓ) 单调下降（秩变小），中后层加速；
  若此预测不成立，说明 rank 定义或数据管道有 bug。
- **P2**：KW 样本三分占比可测；预期追不上型占多数、塌陷型为少数（先验：无）。
- **P3**：DK 样本 r_ext/r_self 全程高且平坦（低信号）。
- **P4**：塌陷拐点层 ℓ_c 与"分道扬镳层"（正确/错误轨迹首次分离的层）相关。
- **P5**：LLR_ext(ℓ) 与 LLR_self(ℓ) 的逐层相关系数 >0.9 → 合并增益锁死（预测
  层间 LLR 合并的增益小到不可测）。
- **P6**：序列级与首 token 轨迹一致率；不一致集中于功能词首 token 样本。

## 5. 失败模式预判

1. **平凡轨迹**：任何"逐层精化分布"的架构都给出"正确上升/错误落后"——观测到
   规律 ≠ 发现机制；只有三分占比、拐点位置、相关系数这些**非平凡量**才有意义。
2. **尺度污染**：若直接用 logit/probability 绝对值跨层比较，结论全废（C1 违例）。
3. **别名污染**：噪声定义含别名 → SNR 系统性低估（C2 违例）。
4. **首 token 歧义**：功能词首 token（the/a/，）使 r_ext 虚高（假知道）→ 主诊断
   用内容 token + 序列级对照。
5. **IB 冲突**（训练侧专用）：深层丢弃浅层信息的"塌陷"可能是压缩的最优行为，
   不是缺陷；任何"惩罚塌陷"的训练设计需先证明塌陷丢弃的是答案证据而非冗余。
6. **无发射端红线**：追不上型样本的 LLR_ext 全程为负 → 数学上任何层间合并都
   翻不了号；干预实验对这类样本预期零效应。

## 8. 监督-校验思想：路线 A（线性监督矩阵）

### 8.1 数学原型

线性码：码字满足 H·c = 0；接收 y = c + e，校验子 s = H·y = H·e——**只依赖
错误图案，与码字无关**；译码 = 从 s 解最小权 e；纠错半径由最小距离 d 代数保证。

### 8.2 定义域命门（"码字"是什么）

| 码字定义 | 可行性 | 致命问题 |
|---|---|---|
| 事实正确的答案 | ❌ | 循环定义（校验为判正确性，构造 H 又需正确性标签）；码字集无法预枚举 |
| 与输入自洽的输出 | ✅ 可定义 | 自洽 ≠ 正确（可自洽地错）→ 检测天花板 = 不一致幻觉占比 |
| 内部状态合法流形（正确样本的 h 满足 H·h≈0） | ✅ 可无监督构造 | 低方差方向 ≠ 对错判别方向，判别力无保证 |

→ 只能走"合法流形"版本（唯一无标签循环）。

### 8.3 退化警告（路线 A 的三个换皮风险）

1. 用对错标签训练 H = 线性 probe（无新意）；
2. rank-1 校验 = truth direction；零空间投影修正 h' ← h − H⁺(H·h) = RepE/子空间
   投影干预的推广；
3. 连续域无 GF(q) 最小距离结构 → "必可纠"类代数保证全部失效。
→ 唯一超出已有方法的结构：**向量校验子的错误定位**（哪些行大 ↔ 错误类型）。

### 8.4 非线性码的结论（为什么路线 A 的线性是必要的）

非线性码存在且可严格更优（Nordstrom-Robinson (16,256,6)：同参数下码字数为任何
线性码的 2 倍），**但校验子是线性（陪集）结构的专利**——非线性码校验退化为
最近邻搜索（NP-hard）。现代实用强码（Turbo/LDPC）全是线性的，正是为了校验子
可计算。对 LLM：要么接受线性近似（保住校验子），要么放弃校验子滑向判别器家族。
Preparata/Kerdock 码"二进制非线性 = Z4 线性"提示：关键是**找对代数结构**（→ §9）。

### 8.5 可检验预测

- **P-H1**：正确样本 ‖H·h_ℓ‖ 逐层低于错误样本，且分道层与 SNR 轨迹分道层（P4）重合；
- **P-H2**：校验子向量方向模式与错误类型（KW/DK/塌陷）稳定对应（错误定位）；
- **P-H3**：零空间投影修正在塌陷型样本上恢复 y* 排名，且与层间回退**互补**；
- **P-H4**：rank-k 校验 AUROC 优于 rank-1 truth direction（多维约束 > 单方向）。

## 9. 监督-校验思想：路线 B（结构适配：残差流）

### 9.1 剥离线性代数后的三条精髓

1. 校验是低维指纹（不枚举合法全集）；
2. 校验子与错误分离、且携带位置/类型分辨力；
3. 修正 = 最小改动回到合法域。
→ 按这三条为 LLM 结构重新设计，而非搬数学。

### 9.2 四个结构适配候选

| 设计 | LLM 天然冗余 | 校验子 | 定位结构 |
|---|---|---|---|
| ① 跨层一致性 | 信息被 L 层反复加工 | Δh_ℓ = h_ℓ − h_{ℓ−1} 在正常子空间补空间的分量 | **逐层序列**：哪层异常 = 错误在哪层 |
| ② 输入锚定 | 答案表征须与问题语义对齐 | h_ℓ 偏离"x 确定的期望表征流形"的距离 | 全局 |
| ③ 多路分集 | 多注意力头冗余计算 | 各路读出分歧度 | 按头 |
| ④ 轨迹描述子 | 健康解码轨迹稳定 | SNR/LLR 轨迹与健康轨迹分布的统计偏离 | 按 (层, token) |

### 9.3 关键结构洞察：残差流是 LLM 里天然的加法结构

h_L = Σ_ℓ Δh_ℓ（路径展开严格加法）。"码字" = 残差增量序列 (Δh_0, …, Δh_L)；
校验 = 检测哪些增量异常（贡献了不该有的/该贡献的没贡献）。收益：
- 校验子逐层可定位；
- 修正 = 对异常增量做最小改动（**定向增量修正**：h_L ← h_L − λ·(异常分量)），
  比"回退整个 logits"精细得多；
- 与 SNR 整合：LLR 塌陷层 ℓ_c = 症状定位，异常 Δh_ℓ = 病因定位。

### 9.4 修正形式的对应（"纠错"的 LLM 形式）

- ① 异常 → 定向增量修正（只剔除问题层贡献的噪声分量）；
- ② 异常 → 表征牵引（朝"与 x 一致"方向移动，零空间投影的流形版）；
- ③ 异常 → 路间共识加权（多路读出重加权）。
全部可微、有定位依据、不靠扫参。

### 9.5 边界（写死）

1. **天花板与三分占比绑定**：自监督校验只检测"偏离模型自身正常模式"的异常
   （塌陷型/不确定型）；追不上型（分布内自信错）的校验子可能全程正常。
2. **自洽性 vs 正确性二选一**：合法流形用正确样本估计 → 退化判别器；用模型自身
   高置信样本估计 → 只检测自洽性破坏。**倾向后者**（概念干净：校验回答"生成
   过程正常吗"，不回答"答案对吗"）。
3. 残差增量正常子空间 ≠ 对错判别方向（低方差无判别力保证）→ 靠 P-H1 交叉验证。

### 9.6 路线 A/B 关系

- A = 线性近似（H 作用于 h 切空间），校验子可算但表达力受限；
- B = 结构适配（校验定义在残差增量上），贴合模型结构、定位精细；
- 阶段 1 存档同时覆盖两者（h_ℓ 与 Δh_ℓ），观测后按 P-H1/P-H2 择一路径。
