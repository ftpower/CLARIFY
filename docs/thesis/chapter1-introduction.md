# 第 1 章 绪论

## 1.1 研究背景

大语言模型（Large Language Models, LLMs）在自然语言处理领域取得了革命性进展。以 GPT-4、Claude、Qwen 等为代表的现代 LLM 展现出强大的知识记忆、逻辑推理和文本生成能力，被广泛应用于问答系统、代码生成、内容创作等知识密集型任务中。

然而，幻觉（Hallucination）问题始终是 LLM 部署面临的核心挑战之一。所谓幻觉，是指模型生成的内容与事实不符、与输入上下文矛盾、或逻辑不一致的现象。在医疗咨询、法律分析、金融决策等高风险场景中，幻觉可能导致严重后果，因此幻觉检测与干预成为可信 AI 研究的关键课题。

从技术角度看，LLM 的文本生成过程是一个逐 token 的自回归采样过程。在每个生成步 t，模型基于前文上下文 h_t 产生下一个 token 的概率分布 p(x_{t+1} | h_t) = softmax(W_U · h_t)。当模型内部表示与最终输出之间存在不一致——即模型"知道"正确答案但未将其映射为 argmax token——时，幻觉便发生了。这种现象暗示了幻觉的根源不仅在于模型知识的缺失，更在于知识从内部表示到输出 logits 的"传输"过程中发生了扭曲。

本研究正是从这一观察出发，将 LLM 的生成过程类比为通信系统中的信号传输过程，提出了 TLDC（Truncated Layer-wise Delta Correction）框架，通过分析模型不同层之间的通道增益变化来检测和干预幻觉。

## 1.2 幻觉问题定义与分类

幻觉是一个多层面的概念。根据现有文献和本研究的实验观察，我们将幻觉分为以下类别：

**按来源分类**：

1. **知识缺失型幻觉（Don't-Know, DK）**：模型训练数据中缺乏相关知识，或知识存储在参数中的方式不足以支持正确推理。表现为正确答案的 token 在 logits 排序中处于极低位置（rank > 50），模型"不知道"正确答案。

2. **知识覆盖型幻觉（Known-Wrong, KW）**：模型参数中存在相关知识（正确答案 token 在 logits 排序中处于较高位置，rank ≤ 50），但在实际生成中，distractor token 的 logit 值异常放大，导致模型"知道却选错"。这是本研究关注的核心幻觉类型。

3. **上下文冲突型幻觉**：模型正确理解了上下文，但上下文本身包含错误信息，模型忠实地"复述"了错误。

**按表现分类**：

1. **事实性幻觉（Factual Hallucination）**：生成内容与客观事实不符，如错误的历史日期、虚构的人物关系等。
2. **忠实性幻觉（Faithfulness Hallucination）**：生成内容与输入上下文不一致，如摘要中出现原文未提及的信息。
3. **逻辑性幻觉（Logical Hallucination）**：生成内容的推理链条存在矛盾或跳跃。

本研究聚焦于**封闭域问答场景中的事实性知识覆盖型幻觉（KW）**，以 TriviaQA 为主要实验数据集，以 Exact Match 为主要评估指标。

## 1.3 研究动机与核心问题

现有幻觉研究面临三个核心瓶颈：

**瓶颈一：检测与干预的割裂**。大多数研究将幻觉检测（判断是否会产生幻觉）和幻觉干预（修正幻觉输出）作为独立任务处理。检测方法的 AUROC 可能很高，但检测到幻觉后如何转化为有效的干预信号，缺乏系统性分析。本研究的核心目标之一，就是构建从检测到干预的完整闭环。

**瓶颈二：推理时干预的信息论局限**。大量工作试图在推理时通过操纵隐藏状态或 logits 来抑制幻觉（如 ITI、RepE、DoLa 等）。本研究系统性测试了 10 余种推理时干预方法，发现它们的一致模式是：隐藏空间中的"正确方向"本质上是 readout 方向（用于事后读取模型知识），而非 control 方向（用于事前控制生成输出）。推理时对该方向的修改无法因果性地改变模型行为。

**瓶颈三：跨规模泛化的黑箱**。许多幻觉检测和干预方法在小模型上验证有效，但在大模型上的表现缺乏系统分析。本研究发现，基于通道增益的 δ 信号在 1.7B 和 8B 模型之间存在根本性差异——小模型上 KW 样本的 δ 反而最小（与"δ 大 = 幻觉"的直觉矛盾），而大模型上 δ 的 override 信号与合法精炼信号在标量层面无法解耦。理解这一跨规模行为的根源，是推进幻觉研究的关键。

## 1.4 研究目标与贡献

基于上述动机，本研究设定以下目标：

1. **构建统一的幻觉分析理论框架**：提出 TLDC（Truncated Layer-wise Delta Correction）框架，从通信信道视角形式化分析幻觉的检测与干预问题，明确信息论层面的能力边界。

2. **系统性评估检测方法的能力与局限**：验证 Truth Direction 方法的检测性能（AUROC 0.91），分析标量 δ 与向量化 g_vec 的表达能力，并通过 Oracle 实验确立检测驱动拒绝策略的信息论上限。

3. **实现训练时干预的有效闭环**：提出 LoRA δ-Corrective 方法，在 1.7B 模型上实现首个有效的训练时幻觉干预（KW +2, KC 0，双 Gate 通过）。

4. **揭示跨规模泛化的信息论边界**：在 8B 模型上系统性验证检测与干预方法的泛化能力，通过 9 个改良维度的穷尽性消融实验，确立 δ 信号在大模型中不可解耦的根本限制。

**核心贡献总结**：

1. **TLDC 框架**：首次将 LLM 幻觉问题形式化为通信信道估计问题，为幻觉检测与干预提供了统一的数学语言和分析工具。

2. **检测-干预闭环**：在 1.7B 模型上实现了从检测（AUROC 0.91）到训练时干预（双 Gate 通过）的完整闭环，证明训练时参数修正可以因果性地改善幻觉行为。

3. **系统性负结果贡献**：通过 10+ 推理时干预方法的对比实验、9 个标量 δ 改良维度的消融分析、Oracle Detect-and-Reject 上限测试、以及知识冲突注入 KW 合成实验，确立了当前技术路线的能力边界，为后续研究提供了有价值的经验指导。

4. **跨规模机制分析**：揭示了 δ 信号在 1.7B 和 8B 模型之间的极性反转和纠缠度差异，从信息论角度解释了幻觉干预在大模型上更困难的结构性原因。

## 1.5 论文结构

本文共分七章，结构如下：

- **第 1 章 绪论**：介绍研究背景、问题定义、研究动机与核心贡献。
- **第 2 章 相关工作**：综述幻觉检测与干预的现有方法，涵盖置信度基方法、内部表示方法、推理时与训练时干预技术。
- **第 3 章 TLDC 框架**：详细阐述通信信道视角下的幻觉分析框架，包括通道增益定义、δ 分解、信息论边界推导。
- **第 4 章 检测**：报告 Truth Direction 方法的实验结果，分析 δ 和 g_vec 的检测能力与局限。
- **第 5 章 干预**：从推理时干预的系统性失败出发，引出 LoRA δ-Corrective 训练时干预的设计、实验与消融分析。
- **第 6 章 跨规模泛化与信息论边界**：呈现 8B 模型的验证结果，讨论 δ 不可解耦性的理论与实验证据。
- **第 7 章 总结与展望**：总结主要发现，讨论局限性，展望未来研究方向。
