# Phase 20.1 8B 三条改进路径失败分析 & 新方向

> 2026-08-08 | 三条路径全部反向优化，系统性诊断 8B vs 1.7B 差异

## 实验回顾

| 方向 | KW Δ | KC 退化 | Gate | 说明 |
|:---|:---:|:---:|:---:|:---|
| 原始 (λ=0.0025) | +1 | -2 | 单 ✅ | 8B 最佳基线 |

## §1 理论诊断：为什么 8B 系统性差于 1.7B？

### 1.1 有效信号密度

LoRA δ-Corrective 训练时，δ 惩罚施加于所有样本（kc_ce_only 下排除 KC）。统计每个 batch 中的信号组成：

| 指标 | 1.7B | 8B |
|:---|---:|---:|
| KC（正确，需保护） | 16/200 (8%) | 60/200 (30%) |
| KW（错误，需修正） | 11/200 (5.5%) | **7/200 (3.5%)** |
| DK（不知道，信号模糊） | 73/200 (36.5%) | 33/200 (16.5%) |
| 总样本 | 200 | 200 |

**有效信号密度** = KW / (KC + DK) = δ 惩罚落在需要修正的样本上的比例。

- 1.7B: 11 / (16 + 73) = **12.4%**
- 8B: 7 / (60 + 33) = **7.5%**

8B 每轮训练中，**92.5% 的 δ 惩罚落在不需要修正的样本上**。模型学到的是"全局压制 δ 通道"→ 包括 KC 样本中的合法精炼信号。

### 1.2 δ 信号的语义稀释

δ(t|x) = y_last(t) - y_ref(t) 是一个**标量通道增益**。它不区分 override 的两种来源：

1. **Override δ**（坏）：模型在后期层用错误信息覆盖早期层的正确答案
2. **Legitimate δ**（好）：模型在后期层用更多信息精炼/确认早期层的答案

1.7B 后期层做的合法计算少（KC 仅 16），override δ 在信号中占主导。
8B 后期层做了大量合法计算（KC=60），legitimate δ 淹没了 override δ。

**核心结论**：δ 通道增益在强模型上不再是 override 的可靠代理。

### 1.3 三条改进路径为什么反向优化？

| 路径 | 设计假说 | 失效机制 |
|:---|:---|:---|
| **Multi-Ref δ** | 多参考层平均可平滑噪声 | 更早层（L24/L26）含更多合法中间信号，引入额外噪声。δ 的跨层变化本身就是合法计算的特征，平滑不掉 override 分量 |
| **v·h 加权** | truth direction 连续权重替代 kc_ce_only 二值开关 | 8B 的 truth direction 分离度弱（1.7B 上 AUROC≈0.90，8B 未知但预期更弱），弱方向信号作为连续权重 = 给模型增加随机扰动 |
| **稀疏 LoRA** | 只调最后 4 层减少合法信号扰动 | δ 是 L28→L36 跨层累积过程。只在 L32-L35 调参意味着 L28-L31 的 override 未被干预，信号路径不完整 |

### 1.4 信息论诠释

δ 通道增益的互信息分解：

```
I(δ; override | x) = I(δ; legitimate_refinement | x) + I(δ; override | x, legitimate)
```

1.7B: `I(δ; override | x)` 在总互信息中占比高（模型简单，合法计算少）
8B: `I(δ; legitimate_refinement | x)` 主导，override 分量被稀释

提高 λ 无助于分离这两者——λ 只控制**惩罚幅度**，不控制**惩罚特异性**。

## §2 四个新方向

按实现难度和理论基础排序。

### 方向 A：增大训练集，提高 KW 密度（最小改动）

**思路**：n_train 从 200 → 2000，KW 期望从 7 → ~35-70。

**为什么可能有效**：
- 更大的 KW 绝对数量意味着每 batch 有更多 override 样本
- kc_ce_only 的保护效果随 batch 中 KC 比例下降而改善
- 1.7B 成功的核心不是模型小，而是 KW 密度高（11/89 = 12.4% vs 7/193 = 3.6%）

**为什么可能失败**：
- 8B 的 KW 绝对比例低（3.5%），增大训练集不能改变比例
- 更多样本意味着更多 KC 也进入训练，kc_ce_only 跳过它们，但 δ 惩罚仍然 92.5% 落在 DK 样本上
- DK 样本中的 δ 仍然被无差别压制

**Gate 预测**：若 KW Δ 从 1 → 2（修正率 14%→29%），且 KC 退化维持 ≤ 2，则通过双 Gate。

**改动**：改 `--n_train` 参数，无代码改动。

### 方向 B：Token 级 δ 分解（信号精细度提升）

**思路**：当前 δ 是对所有 token 的标量惩罚。改为只惩罚**特定 distractor token** 的 logit 增益。

```
Loss = CE(y_true) + λ · max(0, g(d*) - g(y_true) + m)
```

其中 d* 是 KW/KC 样本中 L36 预测的 distractor token（d* = argmax_t≠y_true y_last(t)）。

**与当前区别**：
- 当前：δ 惩罚施加于所有 token → 对合法 token 的增益也施加了反压
- 改进：只惩罚 distractor token → 保留合法 token 的精炼空间

**为什么可能有效**：
- 解决了 δ 信号与合法计算纠缠的问题
- kc_ce_only 保护了 KC 样本的梯度方向，但未保护 KC 样本中合法 token 的增益量——token 级分解可以同时保护合法 token

**为什么可能失败**：
- d* 可能本身就是合法 token（在 DK 样本中，模型确实不知道答案，distractor 只是没有信息的默认预测）
- Token 级信号比标量 δ 噪声更大

**改动**：修改 loss 函数，~30 行。同时改 logit 提取逻辑（不只看 argmax，要看 top-k distractor）。

### 方向 C：对比学习替代 δ 惩罚（信号表示升级）

**思路**：放弃 δ 通道增益。用对比学习在 LoRA 的 Q/V 空间中拉近 y_true 的表示、推远 distractor 的表示。

```
Contrastive Loss = -log( exp(sim(q_proj(h), v_true)) / Σ_d exp(sim(q_proj(h), v_d)) )
```

其中 v_true 和 v_d 分别是 y_true 和 distractor token 的 value projection 表示。

**与 δ 的区别**：
- δ 是**标量幅度**惩罚 → 不改变表示方向
- 对比 loss 是**向量方向**优化 → 直接重塑 Q/V 投影，让正确的 token 更容易被选中

**为什么可能有效**：
- 不依赖 δ 作为 override 代理信号
- 对比学习在低样本密度下比 L2/标量正则更鲁棒
- 在 embedding 空间操作，有方向信息

**为什么可能失败**：
- 需要正负样本对 → 如何选择负样本是关键（只选 distractor？选 top-k？全词表？）
- 对比 loss 的数值稳定性需要仔细调参（temperature、hard negative mining）
- 更大的实现复杂度

**改动**：新 loss 函数 + 修改 forward 的 hook 收集 Q/V 中间表示，~100+ 行。

### 方向 D：组合现有最优 + λ sweep 微调（无新代码）

**思路**：在原始最优配置（λ=0.0025）附近做更细的 λ sweep。

从 λ sweep 结果看：λ=0.0025 是唯一 KW Δ > 0 的点，λ=0.002 和 λ=0.003 都是 KW Δ = 0。这说明 8B 的最优 λ 区间极窄。

**方案**：在 [0.0022, 0.0028] 区间以 0.0001 步长扫描 7 个点。

**预测**：可能找到 KW Δ = 1 且 KC 退化 ≤ 1 的配置（满足双 Gate），但更可能仍然卡在 KW +1 / KC -2。

## §3 推荐执行顺序

| 优先级 | 方向 | 理由 |
|:---:|:---|:---|
| 1 | **D: λ 微调** | 零代码改动，15 分钟内出结果 |
| 2 | **A: 大训练集** | 零代码改动，验证信号密度假说 |
| 3 | **B: Token 级 δ** | 代码改动小（~30行），解决标量信号的核心缺陷 |
| 4 | **C: 对比学习** | 理论最好但实现最复杂，B 失败后再做 |

**停止条件**：任一方向双 Gate 通过（KW Δ ≥ 1 且 KC 退化 ≤ 1）即停止，不再跑后续方向。

**如果全部失败**：承认 8B KW 样本数不足以支撑 δ-Corrective，论文写 1.7B 成功 + 跨规模的样本密度限制分析。
