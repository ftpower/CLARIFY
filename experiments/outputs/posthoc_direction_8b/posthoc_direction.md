## 三项对照（对最优事后特征 `post_beta`）

- **分 seed**：seed123 救回 n=11 / 破坏 n=8 → AUROC **0.841**
- **分 seed**：seed456 救回 n=12 / 破坏 n=6 → AUROC **0.458**
- **分层 t t≤1**：救回 21 / 破坏 13 → AUROC 0.733
- **分层 t t=2–3**：救回 2 / 破坏 1 → AUROC 0.000
- **分层 t t≥4**：救回 0 / 破坏 0 → AUROC nan
- **与 t 的 Spearman**：rho = -0.019（≈0 ⇒ 非步索引假象）
- **干预前对照**：同索引步 `pre_beta` 的 AUROC = 0.283（≈0.5 ⇒ 信息由干预产生）
