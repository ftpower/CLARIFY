## 目的

在会话开始时加载项目上下文，让后续工作有清晰的方向和优先级，不依赖"模型记住上次会话"。

## 步骤

1. 读取 `docs/project-state.md`（当前阶段、核心指标、已完成、下一步）
2. 读取 `docs/plans/current.md`（优先级、行动清单、依赖与阻塞）
3. 向用户简洁汇报：
   - 当前阶段与核心指标状态（检测✅ / 干预❌）
   - 最近进度（上一阶段/上轮做了什么）
   - 当前计划的下一步（行动清单里第一个待办）
   - 是否有阻塞或待确认项
4. 询问用户本次会话的目标（如果还没明确）；若用户已说明目标，对照计划确认它是否在清单上

## 注意事项

- 只读这两个文件就足够恢复状态；`~/.claude/plans/CLARIFY/` 与 memory/ 是归档，仅当需要历史细节时查
- 如果状态/计划文件缺失或过期，先提示用户初始化，不要臆造
- 模型默认是 `deepseek-v4-flash`，复杂推理任务建议提醒用户 `/model` 切 `deepseek-v4-pro`
