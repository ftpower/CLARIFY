## 目的

把本次会话的产出沉淀到文件，保证下次会话能立即恢复状态（不依赖聊天记录）。

## 步骤

1. 汇总本次会话：
   - **完成了什么 / 失败了什么 / 待定什么**
   - **关键结论**：新的实验数据、gate 结果、机制发现（只记事实，不臆造）
2. 更新 `docs/plans/current.md`：
   - 行动清单：完成项打勾，新增下一步，更新优先级
   - 依赖与阻塞：如有变化
3. 更新 `docs/project-state.md`：
   - 当前阶段、已完成列表、关键结论、下一步（如发生变化）
   - 保持"最后更新"日期
4. 检查未 push 的 commit，提醒用户 `git push`（不要自己 push）
5. 向用户汇报：同步了哪些文件、下一步是什么

## 注意事项

- 只追加/更新事实，不编造实验结果
- 归档（`~/.claude/plans/CLARIFY/`、memory/）可选同步，但不作为主事实源
- 如果本会话没有任何值得记录的变化，明确说明"无状态更新"即可，不要为写而写
